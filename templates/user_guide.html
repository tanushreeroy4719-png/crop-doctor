How Crop Doctor works

Four steps from photo to plan.

1

Photograph a single leaf

Use natural daylight, a plain background, and fill the frame with one leaf showing the symptom clearly. Avoid heavy shadows or blur.

2

Upload or try a sample

Drag the photo into the upload zone on the Home page, or pick one of the sample tiles to see the flow end to end.

3

Review the prediction

The model returns a crop, a condition, and a confidence score. Lower confidence usually means the photo is unclear or the symptom is ambiguous — try a second angle.

4

Answer a few questions, get a plan

Short questions about weather, watering, and pest activity let the AI Agronomist tailor its treatment and prevention advice to your actual conditions.

Running this project yourself

1. Install dependencies

pip install -r requirements.txt

2. Train the model on your dataset

Organize your dataset as data/train/<class_name>/*.jpg and data/val/<class_name>/*.jpg (standard PlantVillage layout), then run python train_model.py. This saves model/crop_doctor_model.keras and model/class_indices.json.

3. Run the app

python app.py, then open http://localhost:5000. Without a trained model, the app runs in demo mode so you can test the full flow immediately.

4. (Optional) Turn on AI reports

Set ANTHROPIC_API_KEY in your .env file to generate reports with Claude instead of the built-in rule-based templates.
